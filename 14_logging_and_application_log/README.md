# 14 Logging and Application Log

この章では、FastAPI アプリケーションにおける
「ログ」を通して、アプリの内部で何が起きているのかを観察します。

ログはエラーのためだけに存在するものではありません。
アプリケーションの振る舞いを記録し、
後から説明できる状態にするための仕組みです。

---

## この章の目的

この章の目的は、logging の細かな設定方法を覚えることではありません。

- ログとは何のために存在するのか
- どのようなタイミングでログが出力されるのか
- FastAPI アプリケーションの中でログを書くとはどういうことか

といった **考え方の部分**を理解することを重視します。

---

## この章で扱うこと

- Python の `logging` モジュールを使った基本的なログ出力
- FastAPI アプリケーション内でログを書く位置
- サーバーログ（uvicorn）とアプリケーションログの違い
- ターミナル上でログを観察する方法

---

## この章で扱わないこと

この章では、次のような内容には踏み込みません。

- ログローテーションやログファイルの管理
- JSON ログや構造化ログ
- クラウドサービスへのログ送信
- 本番運用を前提とした詳細なログ設計

これらの話題は、後の章や実運用のフェーズで扱う内容です。

---

## 学習の進め方

1. `main.py` を起動し、ターミナルに表示されるログを確認します
2. エンドポイントにアクセスし、ログが出力されるタイミングを観察します
3. アクセスログとアプリケーションログの違いを意識します
4. なぜその場所にログを書いているのかを考えます
