# 98 HTML Response and htmx（Experimental）

この章は **試験的な章** です。

FastAPI の学習は、ここまで主に
- JSON を返す API
- クライアント（curl / browser）との HTTP 通信

を中心に進めてきました。

しかし実際の現場や「爆速開発」と呼ばれる文脈では、  
FastAPI は次のような使われ方をすることがあります。

- HTML を直接返す
- JavaScript をほとんど書かない
- 管理画面・内製ツール・PoC を素早く作る

この章では、その一例として  
**FastAPI × htmx** の最小構成を体験します。

---

## この章の位置づけ（重要）

この章の目的は次の通りです。

- htmx を使いこなすことではありません
- React の代替を示すことでもありません
- フロントエンド技術を網羅することでもありません

**FastAPI の「射程」を広げて理解すること**  
が、この章の目的です。

---

## この章でやること

- FastAPI で HTML を返す
- Jinja2 テンプレートを使う
- htmx により画面の一部を更新する
- DevTools で HTTP Request / Response を観察する

---

## この章でやらないこと

- JavaScript の詳細な解説
- 状態管理（state management）
- SPA 設計
- フロントエンドフレームワークの比較・優劣

---

## なぜ htmx を使うのか

htmx は、HTML の属性を使って HTTP リクエストを送るライブラリです。

DB → FastAPI → HTML → Browser


という **シンプルな流れ** を維持したまま  
動的な画面を作ることができます。
