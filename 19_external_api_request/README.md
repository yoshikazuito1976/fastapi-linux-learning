# 19 External API Request

この章では、**FastAPI から外部の Web API を呼び出す方法**を学びます。

これまでの章では、FastAPI を使って  
「HTTP リクエストを受け取って、レスポンスを返す」  
という **サーバー側の基本動作**を扱ってきました。

しかし、実際の Web アプリケーションや API は、  
**外部サービスと連携することが前提**になっているケースがほとんどです。

この章では、FastAPI を「APIを受ける側」から  
**「APIを呼び出す側」へ一段階進める**ことを目的とします。

---

## この章でやること

- FastAPI から外部 API を呼び出す基本的な流れを理解する
- `httpx` を使った **非同期 HTTP リクエスト**を体験する
- 外部 API 呼び出し時のエラーや注意点を知る
- これまで学んだ HTTP / request / response の知識をつなげる

---

## なぜ外部 API を扱うのか

実務では、API は単体で完結することはほとんどありません。

例：
- 認証サービス
- 決済サービス
- 通知（メール / Slack / LINE）
- 天気・地図・翻訳・AI API

FastAPI は、これらを **まとめて扱う「ハブ」**として使われることが多く、  
「外部 API を呼べる」ことは必須スキルになります。

---

## 使用するライブラリ

この章では、以下のライブラリを使用します。

- **httpx**
  - 非同期対応の HTTP クライアント
  - FastAPI（async/await）との相性が良い

※ `requests` との違いにも軽く触れますが、  
本章では `httpx.AsyncClient` を中心に扱います。

---

## 学習のゴール

この章を終えた時点で、以下ができていればOKです。

- FastAPI のエンドポイントから外部 API を呼び出せる
- レスポンスを受け取り、必要な形に加工して返せる
- 外部 API が失敗する可能性を意識できる

完璧な設計や実務レベルの実装は **まだ目指しません**。  
「外と通信できる」「つながる感覚を掴む」ことを最優先にします。
